# 可选文本提供者

规则引擎、历史、NPC 条件对话和样例剧情不需要外部 AI。可选服务仅接收模板和调用方明确提供的公开字符串事实，返回描述文本：

```java
getServer().getServicesManager().register(TextProvider.class,
    myTextProvider, this, ServicePriority.Normal);

chronicle.describe("{npc.name}看向远处的档案塔。", Map.of("npc.name", "青芜"))
    .whenComplete((description, error) -> {
        // 返回普通文本。展示需回玩家实体线程；不得解释成命令、条件、效果或奖励。
    });
```

运行时 `TextService` 在独立、有界线程执行提供者调用；`text-timeout-ms` 默认 1500，限制 1–30000 ms。失败、超时、缺失服务、空响应、控制字符、超过 8192 字符的响应或队列繁忙，均回退到本地模板。输入模板最多 4096 字符、公开事实最多 64 项，每项值最多 4096 字符。替换为单次匹配，不会二次解释事实值中的占位符，模板输出最多 8192 字符。

最多允许 32 个尚未真实完成的提供者请求。超时只是让玩家立即使用模板，不会把仍在执行的外部网络请求当作完成并无限启动新请求。一直不完成的提供者耗尽该额度后，后续调用直接回退；管理员应修复或停用提供者。提供者应自行设置网络连接／读取超时和取消机制。

这个接口没有 Bukkit、命令派发、国家服务、奖励服务或数据库句柄。返回 `/op ...` 等字符串也只会是字符串；StarChronicle 从不执行它。服务器插件本身属于可信代码，该接口不能把一个恶意 Java 插件隔离成沙箱。密钥、真实聊天隐私及未公开事实不应放进 `publicFacts`。本项目不捆绑付费模型或密钥。

真实历史书和来源证据不调用该服务，以保留来源准确性。AI 摘要或对话草稿应明确作为描述／草稿展示，不能覆盖历史事件原文与 evidence。测试见 `core/TextServiceTest`。
