## 行为与边界

- 私聊在发送者 owner 捕获名字，目标 owner 复核原会话、在线状态和最新屏蔽，再记录准入并投递；回显返回原发送者 owner。屏蔽／取消屏蔽先在目标 owner 采样名字，再回发起者核验后修改。补全使用已有名字目录，按前缀过滤，回复不再把玩家名当消息建议。
- 退休、注册拒绝、旧会话、模块停用和重复回调不会再投递到替换会话或执行两次。投递异常明确为未确认且不自动重试；回显失败不重发给收件人。已经准入的操作可能结束，不保证两名玩家在同一原子时刻都在线。
- 屏蔽检查、双方回复指针和最多十条历史在短锁内更新，快照不可变，Bukkit 调用在锁外。加载先构造完整独立集合，空列表替换旧偏好，坏输入保留旧状态。退出只清临时消息状态、保留屏蔽偏好；迟到的旧退出事件不会保存或清理新会话。
- 历史代表本地准入，不是客户端确认或持久投递凭据；传输异常可能保留尝试记录。屏蔽沿用异步文件保存，不承诺进程故障后的同步持久性；未修改其他服务的退出／加载策略。
- 原同步构造器和 `SocialService.sendMessage(Player,Player,String)` 保留，调用方必须已拥有两名玩家，不能用作跨区域 Folia 入口。生产模块使用新构造器；公开 API 签名保持，新增准入记录与会话结束接口。
