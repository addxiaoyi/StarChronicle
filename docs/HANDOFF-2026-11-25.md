## 构建与复验

```bash
npm install --prefix run/epic-client mineflayer@4.39.0
export EPIC_MINEFLAYER_MODULE="$PWD/run/epic-client/node_modules/mineflayer"
python3 tools/prepare-epic-paper.py prepare --route DUNGEON --attempt new-attempt --port 29701 --starcore /path/to/starcore.jar --runtime /path/to/initialized-paper
python3 tools/prepare-epic-paper.py compile --run run/PREPARED-DIRECTORY --java-home /path/to/java21
python3 tools/epic-paper-session.py --run run/PREPARED-DIRECTORY --java-home /path/to/java21 --node /path/to/node --boot 1 --scenario tech-first
python3 tools/epic-paper-session.py --run run/PREPARED-DIRECTORY --java-home /path/to/java21 --node /path/to/node --boot 2 --scenario tech-second
```
