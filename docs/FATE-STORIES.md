# 八种身份的玩家命运剧情

八条 `fate-*.yml` 是独立可运行的个人剧情，每条提供两个完整结局。它们复用相同的规则、SQLite 状态、结果去重、称号、荣誉、NPC 声望和历史机制，不引入不存在的 StarCore 脚本或任务 ID。

| 身份事实 `player.role` | 剧情 | 两种方向 |
|---|---|---|
| `soldier` | 城门下的誓言 | 保护平民／记录无名者 |
| `general` | 沙盘之外 | 补给撤离／战争克制 |
| `merchant` | 账本的另一页 | 公平报价／贸易出处 |
| `scholar` | 未完成的注脚 | 公开研究方法／保存疑点反例 |
| `explorer` | 地图边缘 | 安全路线与许可／遗址保护 |
| `diplomat` | 尚未签署的纸页 | 倾听各方／核实共同事实 |
| `mayor` | 广场上的议题 | 民生听证／城市记忆 |
| `monarch` | 王冠的重量 | 保留异议／资源用途问责 |

每条顶层条件只检查可信当前 `player.role`，不使用事件传来的“身份”自我声明。身份仍须来自 StarCore、管理员控制的明确身份权限或受信任上下文提供者。陌生身份或身份缺失不会触发；个人实例不能被其他玩家加入。

所有命运线支持 `PLAYER_JOIN`，并按题材监听已有的国家、战争、领土或科技事件。每日入世事件由运行时按玩家与 UTC 日期提交稳定 ID；`facts.time_basis=OBSERVED` 明确表示观察时间。剧情另有 86400 秒冷却，新的来源 ID 不能绕过冷却，完成后需要后续合法事件才能再次开始。

这些是个人价值选择和公共倡议，不会将一句誓言记成已完成救援、真正的大宗交易、正式军令、生效外交条约、立法、国库支出或国家科技解锁。文本和历史类型均将“提议／承诺”与实际权威状态区分。当地发生真实行动后，应由对应权威服务提供具有稳定 ID 的提交事件接续剧情。

默认结局授予 StarChronicle 本地荣誉和叙事称号，并影响三个逻辑 NPC 中相应人物的声望。它们不兑换物品或货币，也不授予真实国家职位。角色互动可通过 `npcs.yml` 的长期关系、历史反应与条件对话继续展开。

`FateStoriesTest` 验证八身份的隔离、事件元数据不能冒充身份、16 条完整结局、初始状态与结局重启、个人历史证据、冷却和奖励重放去重。最终测试执行结果以统一构建报告为准。
