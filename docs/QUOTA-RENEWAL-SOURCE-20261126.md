# 到期配额的周期推进

2026-11-26，续接贸易模型引用隔离。旧实现到期后只清零 currentAmount，start/reset 不变，所以后续每次 useQuota、交易预留或定时检查都再次判为到期。已经用完的新额度可反复恢复，保存后重启也保持这个错误。

修复保持原配额 ID、国家、资源、类型及上限，按 start/reset 的原周期长度和原始边界直接计算包含当前时间的窗口，替换为清零一次的新模型。窗口内重复调用继续扣额，错过多个周期不积攒额度、也不循环重放。直接使用、交易双方预留和定时检查复用相同推进逻辑；交易失败释放的是本轮自有配额，快照仍独立。

配额创建与推进统一使用可注入时钟，默认 UTC 实际时钟。两个公开构造函数和模型格式保持，包内时钟入口用于确定性测试。大整数余数避免极古老毫秒周期的计数溢出；时间回退不清除已进入窗口的用量。计算及存储毫秒范围检查在替换前完成，下一窗口无法表示时抛错并保留该配额，而不是钳制时间或自动放宽限额。

这不新增每次配额使用的同步落盘。原资源保存周期、提交失败对账及跨服务贸易事务边界保留；测试在明确完成库存保存后重启，不宣称未保存的配额变更具有崩溃持久性。单次定时扫描也不是全部配额共同提交的事务，事件回调及多写入者仍需独立审查。
