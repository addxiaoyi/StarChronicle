统一文件检查重复键、字段／类型、UUID、队长、成员唯一性、容量和时间；记录两个旧文件的 SHA-256，首次保存建立精确字节备份，之后保持原文件。合作 writer 文件锁、已载入指纹比较、force 和原子移动防止陈旧覆盖；临时文件／缺失主文件／遗留恢复证据／旧源变化时拒绝，不静默从旧文件回滚。Windows 目录 fsync 尽力执行，未做硬件断电验证。16 MiB／4M 码点约束文件解析和序列化结果，不宣称所有在内存状态和序列化前分配均受此预算限制。
