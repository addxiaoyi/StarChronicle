## 行为

- 排行榜最多读取当前页 28 个名字及查看者上一名（最多 29）；自带经济异步读取，外部 Paper 经济在全局线程读取，未验证的外部 Folia 提供者拒绝。在线名字在原目标 owner 获取；离线查询异步，返回 Player 时转回其 owner。失败回退 UUID／默认头像，有真实名字时用 UUID＋名字创建独立头像资料。
- 排行榜、家园和星港均先夹紧页码，再渲染与解释槽位。点击事件即时取消，动作在事件后回原 owner 执行，再检查确切 inventory／会话；刷新成功消息在真正打开后发送。
- 最新请求才可替换发起时的界面；换菜单、关闭、退出、重连、停用或任务退休后不再显示旧结果。请求有独立 identity，同玩家同 inventory 的旧回调不能删除新请求；终止路径释放 pending 引用。
- 运行界面使用单个会话记录。旧 quit／close 只清属于原 Player 的状态，不影响新连接。家园书本保存回原 owner，并带原会话／请求标识；不同书本的编辑不能被当成家园输入。
- 书本 token 每次独立，即使物品完全相同也不复用。停用短锁内排空 detached 状态，先取消旧业务任务，再按原 Player＋inventory／book token 安排清理；并发打开中的界面不遗留未登记状态。Bukkit 库存调用位于锁外。
- 原公开 API 与旧同步构造器保留；旧调用方需拥有所有访问玩家并允许同步资料 I/O。实际模块使用新调度构造器。家园提示改为书本填写／签名。
