# 资源交付回执的提交与隔离边界

2026-11-26，续接配额周期修复。原生资源交付写入已同步，但单条 transferReceipt 查询未进入同一监视器，可能在交付持久提交或完整对账尚未结束时返回空值。单条和分页查询也没有检查模块隔离：存储连接恢复后，尚未恢复权威的模块仍可返回回执或空页。

单条查询现在与写入／分页读取共用 ResourceModule 监视器，等待提交及对账结束；两种查询都在锁内检查存储、资源域与隔离状态，不可用时抛出 IllegalStateException。连接恢复不自动解除模块隔离，需恢复模块再核对原编号。交付写入入口也显式检查不确定标记。空编号仍返回空，非法分页参数继续先被拒绝。

提交前／提交后异常仍返回 UNKNOWN，不将未知结果转换为普通失败或创建新编号补偿。正常恢复之后可查原回执并重试原 ID，保留双库存和工厂／贸易的完整状态。接口的无持久权威默认实现不构成可用证明，调用方仍须先验证 provider 支持。
