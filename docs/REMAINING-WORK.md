## Chronicle 可以继续独立完成

| 优先级 | 缺口 | 实际下一步与验证要求 |
| --- | --- | --- |
| P1 | 退休剧情版本的配置引用目录 | 当前新配置只校验当前目录的目标版本；API与旧pinned快照能读旧日志，不等于任意退休版本都能被新文件引用。增加来自实际持久化定义的只读版本目录，明确同版本不同定义冲突、旧版本节点与选项来源；不能用虚构空定义通过校验。 |
| P1 | 已有正史显式启动后来安装的新内容 | 旧V2结果不会自动补排新后续。可增加受权的、单个 canonical source＋新规则的显式评估，不改旧事件或冒充恢复当年资格。必须为缺少V2 scope receipt但已有完成实例的情况补防护，不能覆盖旧JSON或重复创建；同时保留因果与新定义快照。 |
| P1 | 新旧内容版本同时排队的细分策略 | 当前相同story/scope的活动实例吸纳新来源，保留旧图。继续定义不同版本是否等待／消费、冷却与新版本资格，避免新来源只被旧图吸纳后没有执行新内容。需要跨重启和并发版本回归。 |
| P1 | 成员换国／国家消失后的复核流程 | 当前活动实例及原生请求绑定原国籍，变更后保守拒绝继续；尚无完整的投票撤回、退出、重新核验与审批API。应保留原投票国籍与历史，提供明确待复核状态，通过当前权威服务重新验证；不能靠改JSON、提升称号或跳过权限解除绑定。 |
| P2 | 真正一国一席的国家级史诗 | 现有WORLD quorum按不同玩家计数，先达人数决定共同路线。新增正式国家代表、可并存国家立场、国家投票单位和稳定决议，不把世界共识或NPC称号当作国家授权。 |
| P2 | 完整史诗战略链 | 当前支持／救济／遗迹／谈判是可玩的叙事提案与分支，不是完整的国家援助、真实遗迹任务、外交承诺与最终战役链。应绑定实际权威操作和任务完成证据，让不同国家长期并行参与。 |
| P2 | 任务和战役完成闸门 | 现有 `quest.accept`／`narrative.start` 只代表投递，不自动等待完成。增加实例／主体／任务运行ID关联的await状态与配置验证，消费真实提交结果，不能另写任务目标解释器。 |
| P2 | 长期贡献账本 | 现有荣誉、称号、NPC关系和投票已持久化；尚无通用资源援助、贸易贡献与文明贡献账本。来源操作ID＋贡献类型＋主体去重，与实际交付回执关联，不能把选择“援助”当成已经扣款。 |
| P2 | 自动世界记忆配方 | 已有逻辑记忆、真实事件绑定纪念点、见证者与图书。新增事件→配方→后续信号／展示登记，以来源＋配方去重，自动筛选相关城市支线；实际施工仍需服内保护授权。 |
| P2 | 真实探索生产者 | 可在本插件拥有的配置地区上记录真实玩家首次到访，以实际位置／地区稳定ID、当前主体与本地提交回执产生探索事件。需要Folia移动／传送线程、世界UUID变更、重复到访和停服恢复测试；目前仍只有可信API入口，没有自动地区发现器。 |
| P2 | 长期容量与维护 | 国民／GLOBAL待触发种子的长期保留、权限投影归一化、选择迁移的超大存档内存上限和历史查询负载尚需压力实测与运维策略。不能通过删除已发奖励回执来减少空间。 |

YAML/JSON内容格式、严格验证器、NPC条件对白、八身份、可选AI接口和无AI回退已有实际实现，不在此重复列作空白。原需求没有强制拖拽式可视化编剧器，不能把它当作文件内容编辑没有交付。

## 必须有真实上游权威或部署支持

| 完整目标 | 仍缺的真实条件与必须保留的边界 |
| --- | --- |
| 原生指定首都迁移 | 审计 `CityService` 没有持久指定首都getter／提交事件；最高等级城市和缓存位置不是迁都证据。已有完整快照SPI和[合同提案](CAPITAL-AUTHORITY-CONTRACT.md)，还需真实实现及部署验证。 |
| 精确无损全类历史 | 快照只证明观察到的变化，不能重建两次扫描间发生又撤回或已清理的事件。需要源系统持久提交日志、稳定操作ID、真实时间与主体；保留OBSERVED、完整scope及首轮基线语义。 |
| 重大贸易与文明生产自动入史 | SenLuo审计对象是烹饪／CraftEngine内容，其可取消回调没有稳定提交回执。需真实交易所／生产账本的post-commit来源；普通提取／收割或demo不等于大型贸易。 |
| 财政援助、资源交付、复国、正式外交与真实战争 | 内置权威适配器只做真实创始人授权的外交邀请，不强制对方结盟。其余操作逐项通过实际StarCore服务重检权限、主体、线程与原子性；不调用模型setter或控制台管理命令替代。 |
| 跨插件变更／外部奖励严格一次 | 现有上游API不接受共同提交的Chronicle outcome ID。本地outbox阻止盲目重放，UNKNOWN需要独立对账；若承诺端到端严格一次，上游必须提供持久幂等键和可查询回执或同一事务。 |
| 后注册原生任务的恢复 | 已有[候选补丁及针对性测试](../patches/README.md)，不是全服部署已生效。默认不启用三项自定义原生任务；需部署核验修复，实际验证两次重启、进度、原始开始时间、存储隔离及奖励边界。 |
| StarCore全栈Folia | 审计原版缺完整声明和所有权调度；GUI、计时、保存、Boss等还需全链路移植。部分所有权合同补丁和本插件独立模式实测都不能替代全栈验收；Folia原生narrative仍关闭。 |
| 真实职务升迁与身份来源 | 当前可读实际创始人、标准rank、显式管理员身份权限和可信扩展。陌生职务体系仍需服内映射；本地历史称号与NPC职位不授予国家权限。 |
| 第三方NPC与领地保护的生产组合 | FancyNpcs／Citizens／Adyeshach交互钩子已有，但未完成所有实际安装版本组合验收，也不接管它们的实体。自动第三方NPC创建和领地施工需其生命周期／保护API与管理授权。 |
| 可选真实AI服务 | TextProvider、有界文本调用及模板回退已存在；具体服务、网络超时与隐私策略仍需部署。它是可选项，规则系统不依赖AI，返回文本不能变成命令、奖励或国家变更。 |

## 后续推进与完成门槛

先完成当前连续叙事构建对应的真实 Paper／Folia回归与源代码检查点，再实现历史版本目录和显式历史评估，随后扩展国家席位、任务闸门、探索生产者与记忆配方。

每项都必须有实际源代码、配置、持久化／迁移／权限测试和对应构建证据。上游能力还须记录实际版本、安装配置、真实主体操作及重启结果。默认剧情的国家提案、接口存在、候选补丁或standalone通过都不算完整目标已经实现。
