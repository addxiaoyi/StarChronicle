## 必须有真实上游权威或部署支持

| 完整目标 | 仍缺的真实条件与必须保留的边界 |
| --- | --- |
| 原生指定首都迁移 | 审计 `CityService` 没有持久指定首都getter／提交事件；最高等级城市和缓存位置不是迁都证据。已有完整快照SPI和[合同提案](CAPITAL-AUTHORITY-CONTRACT.md)，还需真实实现及部署验证。 |
| 精确无损全类历史 | 快照只证明观察到的变化，不能重建两次扫描间发生又撤回或已清理的事件。需要源系统持久提交日志、稳定操作ID、真实时间与主体；保留OBSERVED、完整scope及首轮基线语义。 |
| 重大贸易与文明生产自动入史 | SenLuo审计对象是烹饪／CraftEngine内容，其可取消回调没有稳定提交回执。需真实交易所／生产账本的post-commit来源；普通提取／收割或demo不等于大型贸易。 |
| 财政援助、资源交付、复国、正式外交与真实战争 | 内置权威适配器只做真实创始人授权的外交邀请，不强制对方结盟。其余操作逐项通过实际StarCore服务重检权限、主体、线程与原子性；不调用模型setter或控制台管理命令替代。 |
| 跨插件变更／外部奖励严格一次 | 现有上游API不接受共同提交的Chronicle outcome ID。本地outbox阻止盲目重放，UNKNOWN需要独立对账；若承诺端到端严格一次，上游必须提供持久幂等键和可查询回执或同一事务。 |
| 后注册原生任务的恢复 | 已有[候选补丁及针对性测试](../patches/README.md)，不是全服部署已生效。默认不启用三项自定义原生任务；隔离 Paper retry27 已验证两次重启、实际进度、原始开始时间、存储域及奖励边界；仍需目标生产组合部署核验。 |
| StarCore全栈Folia | 审计原版缺完整声明和所有权调度；GUI、计时、保存、Boss等还需全链路移植。部分所有权合同补丁和本插件独立模式实测都不能替代全栈验收；Folia原生narrative仍关闭。 |

## 后续推进与完成门槛

版本目录 schema 5 检查点的 514 项 Maven、Paper 43 项、Folia standalone 45 项、真实迁移及 Linux CI 证据继续保留。当前新构建 800 项 clean verify 通过；当前 `4ede86a8` 配置地区探索已完成自身精确指纹的 Paper／Folia 实服验收及每平台九项独立证据回归；原生候选 focused 44 项通过但 StarCore 完整回归失败，各次 Paper 失败与未完成记录均保留。UNKNOWN 对账和失败／放弃后的安全新轮次仍需实现。
